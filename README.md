## 📝 Problem Description  

In group projects, class tours, or shared classroom activities, managing expenses is often messy.  
- Usually, one person keeps manual records → errors happen.  
- Leads to **confusion, unfair settlements, and conflicts** among group members.  

---

## 💡 Proposed Solution  

Classroom Expense Splitter is a **mobile application** that simplifies group expense management which:  
- Allows users to **create groups** and **add members**.  
- Records and stors all expenses in **Firebase Firestore (real-time database)**.  
- Calculates each member’s balance.  
- Ensures **fairness, accuracy, and transparency** in cost-sharing.  
- Provides real-time updates for all group members.  

---

## 📖 Project Description  

This app helps tracking expance for any event in a community or institution. It records , calculates and stores expanse information from the group members for the events.

### ✨ Key Features  
- ➕ Create Group  
- 👥 Add Members  
- 💵 Add Expenses  
- 🔢 Automatic Balance Calculation  
- 📊 Expense Summary Report
